# Brand

Platform brand is **iCanOva**. Product display names:

- Platform: **iCanOva Monitoring**
- Edge family: **iCanOva Edge**
- Edge product: **iCanOva Edge Gateway**

Canonical JSON (this repo): [`../product/product-identity.json`](../product/product-identity.json)  
Terminology: [`../product/terminology.md`](../product/terminology.md)

Full visual specification lives in the edge gateway repository `doc/brand/` (GitHub: `icanova-edge-gateway`). This application uses the approved colour tokens and typography in `src/styles.css`. Final logo assets are on hold; the UI uses a text wordmark.

Do not treat Deep Sea Electronics (DSE) equipment names as the product brand.
