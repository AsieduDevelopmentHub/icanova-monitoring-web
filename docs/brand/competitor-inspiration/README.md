# Competitor inspiration (Invendis / American Tower style)

Screenshots captured for UI/UX reference. **Do not copy branding, logos, or layout verbatim.** Use these as a competitive benchmark: density, information architecture, and the catchy **graphical / power-flow** surfaces.

iCaNova focus today: **generators + gateways + site monitoring** — not full tower tenancy / multi-tenant DC product scope.
